# Jobconfirmation.Ai

A job-opportunity website focused on presenting verified career listings.

## Stack
- HTML
- CSS
- Vanilla JavaScript
- Supabase
- Google AdSense

## Project files
- `index.html` — main website, styling, UI and application logic
- `sw.js` — service-worker notification handling
- `ads.txt` — advertising authorization

## Local preview
Open `index.html` in a browser, or serve the folder with any simple static HTTP server.
